# AGENTS.md — Rules for AI coding agents on this project

**The rules live in [CLAUDE.md](CLAUDE.md). Read that file and follow it in full.**

Everything in it applies regardless of which agent or tool you are — the public-repository
constraints, git and commit discipline, project hygiene, the configuration rules, the code
quality rules, and the security rules for handling untrusted input.

Two substitutions to make as you read it:

- Wherever it says "Claude Code", read it as whichever agent you are.
- The commit-message rule — *never mention Claude, AI, or any AI tooling* — is about **all**
  AI tooling, not Claude specifically. No "Generated by", no "Co-Authored-By", nothing that
  identifies a tool. Commit messages read as if written by a human developer.

## Why this file is a pointer and not a copy

Two copies of the governing rules drift, and the moment they do, whichever agent reads the
stale one operates under different rules than the other. On this project one of those rules
is "never commit a secret to what is a public repository", so drift there is not a cosmetic
problem.

If you are tempted to paste the rules back in here so your tool can read them inline: don't.
Read CLAUDE.md instead. If your tool genuinely cannot follow a reference, say so rather than
forking the rules.
